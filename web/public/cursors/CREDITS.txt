pointer.cur is a single static frame extracted from the pack's animated
"Link Select.ani", since browsers only support static cursor images
(.cur/.png/.svg) via CSS `cursor:`, not Windows .ani animation -- same
underlying artwork, just one frame of it.

Files used here (renamed from the pack's originals):
  default.cur      <- Strawberry Pochacco Normal Select.cur
  pointer.cur       <- Strawberry Pochacco Link Select.ani (first frame)
  not-allowed.cur   <- Strawberry Pochacco Unavailable.cur
  text.cur          <- Strawberry Pochacco Text Select.cur
